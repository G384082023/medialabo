「Webコンテンツ作成」の成果

本テーマについて

HTML によって Web ページの構造を記述する基本的な方法がわかる。
CSS によって Web ページの見た目を設定する基本的な方法がわかる。
JavaScript によって Web ページのインタラクティブな処理を記述する基本的な方法がわかる。
HTML, CSS, JavaScript の構文リファレンスから，構文の書式や使用方法の情報を入手できる。
HTML, CSS, JavaScript, 画像・音声・動画ファイルを組み合わせて簡単な Web ページが作成できる。

プロジェクト課題について

私が取り組んでいるプロジェクトは世界の天気に関するものだ。
12つ都市を表示できるプルダウンメニューがある。
選択したい都市をクリックし、検索ボタンをクリックすると、この都市の詳細情報(緯度、経度、天気、最低気温、最高気温、湿度、風速、風向)が表示される。
ボタンを押すと、選択した都市の写真が背景に表示される。
「検索キー」は時間の経過とともに色が絶えず変化し続ける。
1番目と2番目の授業では、htmlファイルとcssファイルのみを使用した。
3回目の授業からはJavaScriptファイルを使用するようになり、cssファイル や htmlファイルの内容をjsファイルに置き換えることができる。

プロジェクト課題で作成したページ： project.html

数当てゲーム

第3回の授業からは、数当てゲームを作るものを書くこと。
Firebox で JavaScript を使用するだけ。
これらの手順は難しいものではなく、答えを予測値と比較する。
If文を使用すればいい。
課題3-1では、予想を4回実行して、予測値は常に4であり、変更する必要はない。
全体として、これらの手順は比較的簡単。
三番目の課題で行ったのは、結果をコンソールに表示することだったが、四番目の課題はその結果を HTML ページに置き換えた。
「◯回目の予想: △」の2行目と「将来ここに判定結果を表示します」の3行目を変更した。
このようにして、正解メッセージまたは間違いのメッセージを表現することができる。
5番目の授業では、ユーザーが入力した数字を確認するためのさまざまな種類のボタンを作成する。
これはinput 要素と呼ばれます。例えば、検索キーや選択肢や数値などがある。
ユーザーの予想の数値をコンソールに取り込み、最終的に回数、予想の数値と判定結果を表示する。
コンソールだけでなく、Web ページにも表示する必要がある。
結論は、３回目から５回目までこの課題を書いてきて、先生の講義の内容が順番に増えていき、このゲームを完成させていくことができた。
難しいのは5番目の授業の内容だと思う。
ユーザーが予想の数値と回数を状況に応じて議論する必要がある。
また、js ファイル中に重複した内容が存在する可能性がある。
その重複した内容をどのように合併して削減するかも、この課題の難しさ。

数当てゲームのページ： kazuate.html

各授業回の学習事項

第1回 WWW と HTM

学習事項:

初回はHTMLの書き方を中心に話す。 最も重要な点はpと/pで最初と最後を囲んだ一部の要素になる。
たくさんの要素がある。 例えば、HTMLでの空白の書き方、HTMLでの特殊なテキストの書き方、HTML文書のコメントの追加方法など。
ハイパーリンクを設定する時は、それぞれの href属性、title属性と target属性を利用する。

演習の成果： HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

学習事項:

第二回の授業の重要なことは、CSS を構築して HTML ファイルに関連付ける方法。
CSS ファイルを使用すると、HTML ファイル内で変更を加えることなく、CSS で変更できる。
たとえば、h1 のテキストの色を変更したい場合は、CSSを使用するだけでいい。
もう一つ重要な点はレイアウト。
レイアウトはフレックスボックスとグリッドレイアウトがある。
フレックスボックスは複数の要素を並べたもので、それぞれの要素の幅を薄くするのは手间がかかるもの。
グリッドレイアウトは、要素を行と列にエリアカットしてその真ん中にサブ要素を構成するレイアウ。
これらを通じて、さまざまな部分内の物事を区別し、それらを背景色で塗りつぶすことができる。

演習の成果： ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

学習事項:

3回目の授業では、主にJavaScriptについて説明した。
JavaScript を追加する方法が様々ある。
先生は私たちに外部の JavaScriptを使用して HTML を書くように言った。
Firefoxのコンソール上で出力結果を確認することができる。
もしエラーが出たときに、エラーメッセージの右側のところをクリックすると、デバッガーのどの行にエラーがあるかを確認できる。
そして、先生はコンソールで簡単なプログラムを教えてくれる。

演習の成果： オブジェクトの参照

第4回 DOM と JavaScript

学習事項:

4回目の授業で学んだことはかなり複雑だと思う。
JavaScript を使用して Web ページのコンテンツを変更する。
これをDOMと呼ぶ。DOM は Web コンテンツを表現するデータ構造。
DOM を学習した後は、HTMLファイルを変更する必要はなく、JSファイルを直接的に変更することができる。
主に学ぶのは、新しい要素の追加と要素の削除。
例えば新しい要素オブジェクトを作成や要素の属性を設定など。
CSSプロパティの変更についても学んだ。

演習の成果： DOMプログラミング

第5回イベント処理

学習事項:

5回目の授業では主にイベントについて学ぶ。
イベントは Web ページ上で起こった動作や出来事のことだ。
授業中、先生はボタンをクリックしたら、背景色をランダムに変更するという練習をする。
RGBカラーでは、赤、緑、青の各色成分がそれぞれ256段階の強度を持つことができる。
そのため、RGBカラーには全部で 256×256×256通りの組み合わせがある。
つまり、16,777,216色のカラーが存在する。
次に、先生はいろいろなinput要素を教えてくれた。
typeの属性を変更することで入力してもらう値の種類を変更することが可能で。

演習の成果： イベントを選択する

工夫点,苦心点,強調点,感想（1000文字以上）

現代社会において、Webデザインは日々のオンライン体験に影響を与える重要な領域となっています。ビジネスサイトや個人サイトなど、Webデザインの質は、他の人やユーザーの体験を左右します。しかし、Webデザインは単なるデザインやレイアウトにとどまらず、多面的な考えと繊細な工夫が求められます。以下は私のWebデザインの途中の工夫点,苦心点,強調点,感想です。
まずはWebのデザインです。良い体験こそがWebのデザインの重要なポイントです。良いデザインは美しいだけでなく、使いやすいものでなければなりません。私たちはデザイナーとして、ユーザーのニーズや心理を考える必要があります。もちろん、学生である私たちも、先生の心理やニーズを考えなければなりません。直感的でナビゲーションしやすいインターフェースを作ります。設計の途中には、プロトタイプの作成とユーザーテストが重要なポイントとなります。先生は私達に設計の上のフィードバックと提案を与えませんが、テストと調整を繰り返して、必ず最終的にユーザー、つまり先生の期待に合うWebページを確保することができます。
次にインタラクティブな要素、つまり「多様性」です。私のWebデザインには、時間とともに変化する文字を1つだけ追加しています。これはインタラクティブな要素とは言えませんが、ぎっしり詰まった文字の中にちょっとした面白さを加えることができます。
3つ目は簡単化だと思います。projectの課題やkazuateの課題では、都市や数字を変える必要があります。例えば、都市を選択する場合、いくつかの方法があります。一つは都市のidをテキストボックスにコピーして検索することです。もう一つは都市の名前をテキストボックスにコピーして検索することです。しかし、私はこの2つの方法が特に良いとは思いません(あくまで個人的な意見だが)。ページの簡潔さ と シンプルさこそが重要だと考えています。12都市のメニューをプルダウンメニューにしました。これが一番分かりやすいデザインだと思います。それでも、名前やidを検索するデザイナーにとって、JavaScriptファイルを書くのは比較的簡単です。しかし、ユーザーの理解や探しやすさこそが、ユーザー体験の重要なポイントです。
感想は次の通りです。Webデザインを始めた当初は、どうでもいいことだと思っていました。情報メディアの授業では、Webデザインよりもアニメーションに触れたいと思っていたのですが、実際にこの授業を始めてみると、また違った考え方をするようになりました。一回目と二回目の授業では、htmlファイルとcssファイルだけで作成するので、比較的簡単でした。ところが、三回目の授業からJavaScriptのファイルを習っていると、だんだん複雑になってきます。授業時間の後、私も多くの時間を使って書きました。ほとんどは一日の午後でした。課題を終えると、達成感が得られます。完成したprojectのページを父に見せました。父も私がとてもよくやっていると思ってくれました。それがWebデザインの魅力なのかもしれません。そのため、Webデザインはその人のセンス、思考力、構図力を反映できると思います。
